# superb-assets

Public images for Superb's email signature (the blinking face badge, the wordmark and the link icons), served by GitHub Pages so email apps can load them.
Only images that are meant to be public go here. The website itself lives in the private all-things-superb repo.

The signatures that use them are in `all-things-superb/signature/mail/`. The face is `superb-face-blink-v3.gif`; the older v1 and v2 were removed on 19 Nov 2026 (still in git history).
